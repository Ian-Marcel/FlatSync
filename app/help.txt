Usage: flatsync [FLAGS]

Flags:
  -a, --automatic
        Automatically and silently performs installations and removals.

  -s, --schedule <minutes>
        Periodically runs FlatSync every <minutes> after an initial execution.
        Default interval is 10 minutes.

      --perma-schedule <minutes>
        Creates a .desktop file in ~/.config/autostart/ to automatically run
        FlatSync at login with --automatic and --schedule.
        Default interval is 10 minutes.
        Note:
          To apply the schedule in the current session, re‑run flatsync with
          --schedule and the same interval.

  -S, --stop-schedule
        Stops the current scheduled process. Use --kill-schedule if the
        .desktop file exists.

  -k, --kill-schedule
        Stops the schedule and removes the .desktop file from
        ~/.config/autostart/.

      --id <action>
        Actions:
          create  Generates a unique identifier for the device (requires sudo)
          get     Displays the current device ID

  -v, --version
        Displays the current version of FlatSync.

  -D, --debug
        Enables verbose debug output. Useful for development or troubleshooting.

  -h, --help
        Prints this help message.
