FlatSync - Flatpak synchronization utility

Usage:
    flatsync [FLAGS]

Flags:
    -a, --automatic
        Automatically and silently performs Flatpak
        installations and removals.

    -S, --systemd <minutes>
        Creates and enables a user-level systemd timer
        for FlatSync.

        FlatSync will automatically run every <minutes>.
        Default interval is 10 minutes.

        Example:
            flatsync -S 15

        This creates:
            ~/.config/systemd/user/flatsync.service
            ~/.config/systemd/user/flatsync.timer

    -R, --remove-systemd
        Stops, disables, and removes the FlatSync
        systemd timer and service files.

        Example:
            flatsync -R

    --id <action>
        Manage the device FlatSync ID.

        Actions:
            create    Generate a new device ID (requires sudo)
            get       Display the current device ID

    -D, --debug
        Enables verbose debug output.

    -v, --version
        Display the current FlatSync version.

    -h, --help
        Display this help message.
